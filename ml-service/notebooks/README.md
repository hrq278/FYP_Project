# How each model was trained

The app runs four kinds of model plus a general image classifier as the cattle gate. This folder records where each one came from and how to reproduce it. Datasets are not in this repository: some have licences that forbid redistribution.

| Model in the app | Trained by | Training material | Reproduce |
|---|---|---|---|
| Breed: ResNet-18, 15 breeds (`model/cattle_breed.keras`) | Team | [breed_training.ipynb](breed_training.ipynb) (outputs stripped; figures are in the breed project's `thesis_outputs/`). Project: `F:\FYP\Models\Breed\cattle-breed-classification-dataset` (`train.py`, `evaluate.py`, `export_keras.py`, `TRAINING.md`) | Run the notebook top to bottom with the dataset from Kaggle `vedant0dusane/cattle-breed-classification-dataset` (CC BY 4.0, 14,443 images, 15 breeds, cluster-aware train/val/test split). The Keras file is exported from the PyTorch checkpoint with `export_keras.py`. |
| Age: MobileNetV3, 5-fold ensemble + incisor segmenter (`model/age/`) | Team | Project `F:\FYP\Models\Age Detection` (script-based, no notebook): `README.md` "Modules" table, `configs/final.yaml`, figures in `outputs/figures/` (F01–F23) and tables in `outputs/tables/` | `python scripts/run_cv.py --config configs/final.yaml`, then `scripts/export_onnx.py`; the 5 folds are joined into `age_ensemble.onnx` (see `PROGRESS.md`, "Model accuracy work"). Dataset: Cattle Dentition Dataset (Patil et al. 2025), **not redistributable**. |
| Health: EfficientNet-B3, FMD / lumpy skin / healthy (`model/health/`) | Third party | Hugging Face model `xprotocol/EfficientNet-B3-Cattle-Disease` (Apache-2.0), pinned to revision `8798052`; model card and test results in `model/health/README.md` | Not retrained by the team. Downloaded by `scripts/download_models.py`. A baseline to be replaced by a model trained on Pakistani photos. |
| Species: MobileNetV2 cow / buffalo (`model/SpecieDetector.keras`) | Team (earlier prototype) | **Missing:** notebook and dataset description not yet provided (FIXES.md item 4) | In the app its cow / buffalo vote now has weight 0 (the gate decides), so it only matters for the legacy `/predict` endpoint. |
| Cattle gate: EfficientNetV2-B0, ImageNet (`model/gate/`) | Keras Applications (Apache-2.0) | Standard ImageNet-1k weights; no training. Rules on top of its ox / water-buffalo / oxcart / ram / bighorn scores are set in `models.yaml` | Tuned with `eval/evaluate.py species` and the studies in `PROGRESS.md` (Modules 1 and 9). |

Measured accuracy of every model as the app uses it: [docs/results/README.md](../../docs/results/README.md), produced by [eval/evaluate.py](../eval/evaluate.py).
