## 2. Architecture

```text
 Mobile App (Expo)  ──►  Backend API (Express, :3000)  ──►  ML Service (FastAPI, :8000)
        ▲                        │                                  │
        │                        ▼                                  │
        └──── result ◄──── MongoDB Atlas ◄──── species + confidence ┘
```

| Service | Folder | Stack | Role |
|---|---|---|---|
| Mobile | `mobile/` | React Native 0.81, Expo SDK 54, Expo Router 6, Axios, AsyncStorage | UI, image capture, auth flow, results |
| Backend | `backend/` | Node.js, Express 4, Mongoose 8, JWT, bcrypt, multer | Accounts, auth, forwards images to ML, stores results |
| ML service | `ml-service/` | Python, FastAPI, TensorFlow 2.21, tf-keras, TensorFlow Hub, OpenCV | Loads model, preprocesses image, predicts |

**Request flow for one evaluation:**
1. User logs in → backend returns a JWT (valid 7 days), stored on the phone.
2. User picks a photo from the gallery or takes one with the camera.
3. App uploads it to `POST /api/evaluate` with the token.
4. Backend forwards the image to the ML service `POST /predict`.
5. ML service resizes to 224×224, normalises to 0–1, runs the model, returns `{ species, confidence }`.
6. Backend saves the result to MongoDB and returns it with a timestamp.
7. App shows the result screen.

## 3. What Has Been Done

### 3.1 Machine Learning

**Species detector — `ml-service/model/SpecieDetector.keras` (in use)**
- Transfer learning: frozen **MobileNetV2** feature extractor (TensorFlow Hub) + Dense(2, softmax) head.
- Input 224×224×3 RGB; output class 0 = Cow, class 1 = Buffalo.
- Confidence is the softmax probability, so it is a real percentage.
- Service includes a fallback loader that rebuilds the model from the `.keras` archive if the normal load fails (this fallback is what currently runs).

**Live test results (Oct 23, 2026, full pipeline through the backend):**

| Test image | Prediction | Confidence |
|---|---|---|
| Black-and-white dairy cow (Wikimedia Commons) | Cow ✅ | 95.55% |
| Water buffalo bathing (Wikimedia Commons) | Buffalo ✅ | 98.95% |
| Text file renamed `.jpg` | Rejected: "Invalid image file" ✅ | — |

Average inference time on CPU: about 1 second per image after warm-up.

**Breed classifier — `ml-service/model/cattle_breed.keras` (trained, unused)**
- ResNet-style CNN built from scratch (residual blocks, GlobalAveragePooling) ending in Dense(15) + Softmax → **15 breed classes**.
- Input 224×224×3 (layer named `normalized_rgb`).
- Saved with Keras 3.12.1 on Sept 28, 2026.
- **The list of the 15 breed names is not saved anywhere in the project.** Without it, predictions can't be turned into breed names.

## 5. How to Run (current, verified)

**Requirements:** Node.js ≥ 20.19, Python 3.13, a MongoDB Atlas cluster, phone with Expo Go on the same Wi-Fi as the PC.

```bash
# 1. ML service (port 8000)
cd ml-service
python -m venv .venv            # only if .venv is missing
.venv\Scripts\activate
pip install -r requirements.txt "setuptools<81" h5py
uvicorn main:app --host 0.0.0.0 --port 8000

# 2. Backend (port 3000)
cd backend
npm install
npm run dev

# 3. Mobile
cd mobile
npm install
npx expo start                  # scan QR code with Expo Go
```

**Environment files:**

| File | Key | Value |
|---|---|---|
| `backend/.env` | `PORT` | `3000` |
| | `MONGO_URI` | Atlas connection string (see note below) |
| | `JWT_SECRET` | a long random string |
| | `ML_SERVICE_URL` | `http://localhost:8000` |
| `ml-service/.env` | `MODEL_PATH` | `./model/SpecieDetector.keras` (default; uvicorn does not read this file automatically) |
| `mobile/.env` | `EXPO_PUBLIC_API_BASE_URL` | `http://<PC LAN IP>:3000` (find with `ipconfig`) |

**MongoDB connection note:** on networks that block DNS TXT lookups (the university network did), the `mongodb+srv://...` string fails with `queryTxt ETIMEOUT`. Use the standard form instead:

```text
mongodb://<user>:<password>@ac-o3ywzcp-shard-00-00.tavy5nf.mongodb.net:27017,ac-o3ywzcp-shard-00-01.tavy5nf.mongodb.net:27017,ac-o3ywzcp-shard-00-02.tavy5nf.mongodb.net:27017/?tls=true&authSource=admin&replicaSet=atlas-9bowx9-shard-0&retryWrites=true&w=majority&appName=fypCluster
```

Also make sure your current IP is allowed under **Atlas → Network Access**.
